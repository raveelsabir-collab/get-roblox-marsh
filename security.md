## 🧠 Reading The Situation Before The Crosshair

Aim assistance is most obvious when it fires in situations where a human would not
have reacted at all. Most of the tuning work is about when it stays out of the way.

**When it should do nothing**

| **Situation** | **Why** |
| --- | --- |
| Target fully behind cover | no human would track it |
| Target outside FOV cone | you were not looking there |
| Target at extreme range | reaction would be implausible |
| You are already tracking | no correction needed |
| Target is a teammate | obvious error |

**The settings that gate those**

- **Visibility gate** handles the first two.
- **Max distance** handles the third — cap it at 150–200 m.
- **Smoothing** handles the fourth, because a high smoothing value produces only a
  small correction when you are already near the target.
- **Team check** handles the fifth, and it should never be off.

**The feel test**

Play a session with the overlay off and count how many times you would have needed
help. Then play with it on and count how many times it fired when you did not need
it. The second number is what gets you caught. Every setting here exists to shrink
that second number.

**Distance is underrated**

Most people tune FOV and ignore max distance. A lock at 400 m across an open map is
far more conspicuous than a tight one at 40 m, because there is no plausible reason
for a player to have acquired that target.

**Order of operations**

1. Close the game and its launcher completely.
2. Run the loader as administrator.
3. Open the **Spoofer** tab and press **Spoof**.
4. **Reboot** — volume serial and SMBIOS are read at boot.
5. Create a fresh account and log in.

**What it does not do**

It does not unban the old account. It gives the machine a new identity so a new
account is not linked to the old ban.

**Skipping the reboot is the most common mistake** — people report "the spoofer
did nothing" when they simply never restarted.
